### 1.1.2 服务职责划分

| 服务名称 | 职责描述 | 核心功能 |
|---------|---------|---------|
| **Gateway Service** | 统一接入网关 | 路由转发、鉴权认证、限流熔断、日志记录 |
| **User Service** | 用户中心服务 | 用户注册/登录、权限管理、配额控制 |
| **Chat Service** | AI对话服务 | 多轮对话、SSE流式输出、Prompt模板 |
| **Task Service** | 异步任务服务 | 任务调度、状态管理、重试机制 |
| **RAG Service** | 知识库服务 | 文档处理、向量检索、语义搜索 |
| **Billing Service** | 计费服务 | Token统计、配额管理、账单生成 |
| **Admin Service** | 管理后台服务 | 系统配置、数据监控、运营分析 |

### 1.1.2 微服务通信矩阵

| 调用方 | 被调用方 | 通信方式 | 协议 | 用途 |
|--------|---------|---------|------|------|
| Gateway | All Services | 同步 | HTTP | 请求路由 |
| Chat Service | User Service | 同步 | OpenFeign | 用户校验 |
| Chat Service | AI Provider | 同步 | HTTP/Stream | AI调用 |
| Task Service | MQ | 异步 | Kafka/RocketMQ | 任务投递 |
| MQ | AI Worker | 异步 | Kafka/RocketMQ | 任务消费 |
| All Services | Redis | 缓存 | Redis Protocol | 缓存/会话 |
| All Services | MySQL | 持久化 | JDBC | 数据存储 |

# 3. 数据库结构设计

## 3.1 数据库设计规范

### 3.1.1 命名规范

```
数据库: ai_platform
字符集: utf8mb4_unicode_ci

表命名:
- 业务表: {模块}_{表名} 如: user_account, chat_conversation
- 关联表: {表1}_{表2}_rel 如: user_role_rel
- 日志表: {业务}_log_{日期} 如: chat_message_log_202401

字段命名:
- 主键: id (BIGINT, 自增)
- 外键: {表名}_id 如: user_id
- 创建时间: created_at (DATETIME)
- 更新时间: updated_at (DATETIME)
- 逻辑删除: is_deleted (TINYINT, 0/1)
- 状态: status (TINYINT, 枚举值)
```

### 3.1.2 索引设计原则

```sql
-- 主键索引: 所有表必须
PRIMARY KEY (id)

-- 外键索引: 关联查询优化
KEY idx_{table}_{field} ({field})

-- 业务索引: 高频查询字段
KEY idx_{table}_{biz}_{field} ({field})

-- 复合索引: 多条件查询
KEY idx_{table}_{f1}_{f2} ({f1}, {f2})

-- 时间索引: 范围查询优化
KEY idx_{table}_created_at (created_at)
``
